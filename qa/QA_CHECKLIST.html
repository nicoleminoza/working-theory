Setup

In Terminal: cd /Users/nicoleminoza/code/working-theory then npm run dev. Open http://localhost:5173 in a real, visible browser window (a hidden tab will not earn theories).

To reset between runs, paste in the DevTools console:

localStorage.clear(); sessionStorage.clear(); location.hash = '#/'; location.reload();

Production build instead: npm run build && npm run preview.

1. Fresh visitor

  • Home shows the hero, three problem rows, Nicole context, and footer.
  • Problem 02 metadata reads Adobe · 2019–2022 →.
  • No "Working theory so far" section, counts, checkmarks, or progress.
  • Footer reads "Working Theory / A project by Nicole Miñoza", with a © 2026 line below a hairline.

2. Partial read

  • Open Problem 02, scroll partway, click "← All problems".
  • Back on home, the row is unchanged and no theory has appeared.

3. Single case read

  • Open a case and scroll until the grey ending band is in view.
  • Return home: that row has a quiet italic line under the problem sentence.
  • "Working theory so far" shows one theory, the synthesis line, and the "I'd like to hear about it" link.
  • Reload the page: everything above is still there.

4. Earned order (clear state before each run)

  • Read 01, then 02, then 03: theories appear in that order.
  • Read 03, then 01, then 02: theories appear 03, 01, 02 (not sorted numerically).
  • Each theory number links back to its case.

5. Navigation and scroll

  • Scroll partway down home, open a row: page fades, case opens at the top.
  • Return with the browser Back button: lands at the exact scroll position you left.
  • Return with "← All problems": same exact position, no smooth scrolling.
  • Load #/01, #/02, #/03 directly in a new tab: each works.
  • Load #/04 or #foo: shows home. Inside a case, changing the hash to either leaves you on that case.

6. Per-case checks

  • Problem 01 (text engine): static; dark governance band and proof numbers display correctly.
  • Problem 02: chart stays pinned beside the steps and changes at each of the six steps, ending on "Paid on use".
  • Problem 02: below 760px wide the chart stacks above the steps.
  • Problem 03 (Typekit): pinned reframe strikes through the old question and brings in the new one as you scroll.
  • Problem 03: the consequence line draws across the five columns as you scroll.
  • All three: the theory in the ending band is the last content before the footer, with nothing appended.

7. Mobile (375px wide, DevTools device mode)

  • No horizontal scroll or clipped text on home, 01, 02, 03.
  • Home row metadata wraps under the problem sentence.
  • Earned-theory section is legible on home.
  • Header does not cover case content.

8. External links

  • Footer "Email" opens a new message to hello@nicoleminoza.com.
  • Footer LinkedIn, GitHub, and nicoleminoza.com open in a new tab at the right place.
  • Make It Land (home context) opens in a new tab at the right place.
  • Résumé → opens in a new tab at the right place.
  • "I'd like to hear about it" (after earning) opens an email to hello@nicoleminoza.com.
